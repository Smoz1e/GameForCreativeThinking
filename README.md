# GameForCreativeThinking

## Запуск
- Откройте `cart.html` двойным кликом, или
- Запустите локальный сервер:

```bash
cd /Users/romankajgorodcev/code/GameForCreativeThinking
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080/cart.html`.
